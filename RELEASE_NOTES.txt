## Important technical notes
- The original `.openai/hosting.json` project ID and D1 binding are retained byte-for-byte.
- Existing prod ACCESS_CODE_HASH and SESSION_SECRET must be retained at deploy time, not generated anew.
- The code contains NO real employee data, NO code hashes and NO production backup.
- The registered 0002 Drizzle migration adds three tables and four indexes. It uses one DDL statement per line for hosted compatibility and installs no triggers. Journal revision and email-confirmation immutability is enforced by the authenticated API; privileged database administrators can modify storage.
- The internal `/api/beta/` route and `beta_*` tables are retained strictly for compatibility with the tested release.
  They are first-party production features after upgrade; they do NOT use Render or Neon.
- Do not publish from the beta repository's `main` branch to production.
- A fresh full JSON backup from the live production API was saved before publication: the private production dataset. The corrected migration was applied twice to its local copy without changing original rows; foreign-key checks passed. Take a final fresh backup if records change before deployment. A native D1 snapshot interface is unavailable through the connected tools; the fresh durable JSON backup, preserved v1.1 git commit and additive migration are the available safeguards.
- The server uses manual SMTP-free mailto drafts and copy-to-clipboard. The website does not send email.

## Manual WhatsApp update - 18 October 2026

- The recipient is fixed to the linked employee's saved country-validated international Contact number. Missing/invalid values require correcting that employee profile.
